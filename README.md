# Quickshell Dynamic Island

A sleek, feature-rich Dynamic Island built with QtQuick/QML for Quickshell on Arch Linux made for people who like the look of minimalism but still want to have a feature rich desktop.

## Prerequisites

* Arch Linux
* Hyprland compositor

---

## Installation

  Clone or download this repository into your local machine.

  Open your terminal in the root folder of the project.

  Run the installation script:

    chmod +x install.sh
    ./install.sh

  Log out and log back in to ensure group permissions (like i2c for brightness control) take full effect.

## Controls & Usage

### Dynamic Island (Center)

  Compact Mode: Displays a minimal status view with active time and system indicators.

  Widget Cycling: Click the island to cycle through multiple interactive views:

  Calendar & Full Calendar: View current dates and navigate monthly schedules.

  Dashboard: Manage your to-do tasks, view live system background apps, inspect active Hyprland windows, and trigger system power actions (Poweroff, Reboot, Logout, Reload).

  App Launcher: Search applications, query files and folders, perform web searches, open YouTube queries, or evaluate math expressions directly.

  Wallpapers: Browse and switch desktop wallpapers instantly via a carousel.

  Performance: Monitor real-time CPU, RAM, SWAP, and Battery usage rings.

  Volume & Brightness Sliders: Quickly adjust output volume or display brightness.

  Weather: Check current conditions and hourly forecasts.

  Clipboard History: Browse, search, copy text, or preview decoded image snippets from cliphist.
  

### Music Island (Left)

  Compact Mode: Shows animated audio visualizer bars when music is actively playing.

  Expanded View: Click to expand the media controller to see track titles, artists, album artwork, progress bars, and playback controls (Previous, Play/Pause, Next).
  

### Settings Island (Right)

  Quick Toggles: View network connection status (Ethernet/Wi-Fi signal strength) and Bluetooth status.

  Volume & Brightness: Fine-tune audio levels and display brightness with interactive sliders.

  Power Profiles: Switch between Power-saver, Balanced, and Performance profiles instantly.

  Appearance Modes: Toggle between Dark, Light, and Glass themes.

  Layout Styles: Switch between standard Island mode and Edge Connected mode.

  Sub-views: Click on Wi-Fi or Bluetooth cards to open dedicated management sub-views for scanning, selecting, and authenticating networks or paired devices.
